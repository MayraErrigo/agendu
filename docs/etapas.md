# Plan por etapas

Cada etapa termina con algo que se puede probar. Si algo falla, no se avanza.

## Cómo trabajamos en cada etapa

1. Objetivo: qué vamos a lograr.
2. Archivos: ruta exacta y código completo; se aclara si es nuevo o reemplaza.
3. Prueba: qué probar y qué tendría que verse.
4. Commit: se guarda en GitHub.
5. Siguiente: recién ahí se pasa a la próxima etapa.
